# UniFi Protect Light

One instance per Protect floodlight, bound to the UniFi Protect Gateway
(SBOS). Commands: Light On/Off, Set Light Mode (always/motion/off, at
fulltime/dark). Events: Motion Detected, Light On/Off, Online/Offline.
Variables: LIGHT_ON, LIGHT_MODE, LAST_MOTION. Auto-names itself after the
floodlight.
