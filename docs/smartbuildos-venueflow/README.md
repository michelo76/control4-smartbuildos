# VenueFlow documentation

VenueFlow is a commercial AV control surface for an existing Control4
project: `drivers/smartbuildos-venueflow`, code in `src/venueflow`, pages in
`ui/venueflow`.

**Standing: simulation verified, not hardware validated.** A bench run has
started (installation, pages, Studio and publishing passed in Simulation; see
HARDWARE_VALIDATION.md). See RELEASE_NOTES.md.

## Quick start without a controller

```bash
make venueflow-dev
```

Then open `http://localhost:47861/` (the operator page, on the simulated
24-display sports bar) and `http://localhost:47861/studio` (Installer Studio;
the development passcode is printed in `tools/venueflow-devhost.lua`).

```bash
make venueflow-test
```

```bash
make venueflow
```

The last builds `dist/oss/smartbuildos-venueflow.c4z` and does not copy it
into Composer's driver folder.
