# Atmosphere — Troubleshooting

First move in every case: action **Print Diagnostics To Log** (with Log Mode =
Print). It prints the full picture — location, office/grid/zone, station and
candidate count, per-endpoint success/failure times with HTTP codes and
consecutive-failure counters, mode/severity/staleness, simulation, license,
settings version, and the app data-relay lines (published URL and relay status,
token always redacted). For app data-plane problems the second move is the app's
own waiting screen: it names the channel it is trying and its build marker (see
[WEBVIEW.md](WEBVIEW.md)).

## Symptom → cause → fix

| Symptom                                                                  | Cause                                                                                                                                                                                                                      | Fix                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Resolved Location` says "outside NWS coverage (US only)"                | The coordinates resolve outside the United States/territories — NWS has no data there. The driver is honest about it rather than guessing                                                                                  | None available from this data source. Verify the coordinates aren't simply wrong (a swapped sign puts you in the ocean); if the property is genuinely non-US, Atmosphere cannot serve it                                                                |
| `Resolved Location` says "Not resolved"                                  | No project location in Composer and no manual coordinates; or the Director project-location XML didn't parse (a known hardware-verification item)                                                                          | Set the project location in Composer, or set **Location Source** = Manual Coordinates and enter Latitude/Longitude; then action **Rediscover Location**                                                                                                 |
| `Weather Status` shows `(STALE)` / `Weather Data Stale` fired            | The controller cannot reach `api.weather.gov`, or NWS is having an outage. Polling is backing off 1→2→5→10→15 min                                                                                                          | Automation holds last-known state; nothing is fabricated. Run **Test Weather API** and read the HTTP code. Check controller DNS/internet. Recovery is automatic (`Weather Data Restored` fires)                                                         |
| Station shows but temperature (or another field) is blank                | Some NWS stations report partial data — a healthy observation can carry several null fields, and quality-control-rejected values are dropped                                                                               | Nothing to fix. Blank means "not reported", never zero. Fields fill as observations arrive; a station stale > 90 min or failing 3 polls in a row is dropped automatically for the next candidate                                                        |
| `Observation Station` keeps changing                                     | Station fallback at work: the nearest station stopped reporting, so the driver walked down the candidate list                                                                                                              | Normal. If it bothers the client, nothing is configurable here by design — the driver always prefers the nearest *reporting* station                                                                                                                    |
| Navigator tile opens a blank page                                        | A `URL_CHANGED` notify sent before the project finished starting is silently lost (measured Navigator behavior) — the driver re-publishes 60 s after startup for exactly this                                              | Wait 60 s after a controller reboot. If it persists: action **Reinitialize Weather Services**, then close and reopen the tile (Navigator will not change the URL of an open web view)                                                                   |
| `License Status` = "No SmartBuildOS Agent Found"                         | No `smartbuildos.c4z` in the project                                                                                                                                                                                       | This is fine — the driver runs fully in LEGACY. Install the Agent only if you want licensing/fleet/remote-settings features                                                                                                                             |
| `License Status` = "Cloud Validation Required"                           | The Agent has been offline past the as-issued (7 d) and grace (10 d) windows                                                                                                                                               | Restore the controller's internet / platform reachability, then action **Refresh License**. Weather automation is unaffected either way                                                                                                                 |
| `License Status` = "Agent Linked - Not Licensed" or "Expired"            | Definitive answer from the backend for this SKU                                                                                                                                                                            | Sort out the license in SmartBuildOS. Weather automation and alerts keep running regardless — only premium display surfaces could ever be gated, and only under server-set enforce mode                                                                 |
| Simulation seems stuck on                                                | Simulation auto-stops on a timeout (default 30 min, configurable 1–480) — you may be inside the window                                                                                                                     | Action **Stop Simulation** ends it immediately. `Simulation` property, `SIMULATION_ACTIVE` variable, the Weather Status prefix, and the app banner all show it while active                                                                             |
| New/renamed events missing in Composer programming after a driver update | Composer caches the driver's event list (known repo-wide quirk)                                                                                                                                                            | Restart Composer after updating the driver, then re-open the programming view                                                                                                                                                                           |
| Everything wrong after experiments                                       | Cached discovery/state is confusing matters                                                                                                                                                                                | Action **Clear Cached Weather** (drops points/station/snapshot/forecast/alert caches and rediscovers; the event baseline resets, so in-progress conditions won't re-announce), or **Reinitialize Weather Services** for a full timer + location restart |
| Driver adds but `Driver Version` stays `unknown`                         | The Lua never initialized — OS below 3.2.0 (check `Driver Status`), or a packaging problem                                                                                                                                 | Verify controller OS ≥ 3.2.0; re-add the c4z; check the Lua output window                                                                                                                                                                               |
| App waiting screen says "No relay address received from driver"          | The driver could not discover the controller's LAN IP — Director returns bindings in project-varying shapes (field-measured), and discovery found no non-loopback IPv4 — so the app URL shipped without a `relay=` pointer | Set the **App Relay Address** property to the controller's LAN IP; **App Data Relay** should flip to "Listening :47815 - serving http://<ip>:47815 to the app". Then close and reopen the tile                                                          |
| App works on the phone but not on a touchscreen                          | The panel is showing a cached copy of the page or the pre-relay app URL — Navigator will not change the URL of an *open* web view, and panels cache across driver updates                                                  | Close and fully reopen the tile; if it persists, reboot the panel. Read the waiting screen's channel line and build marker (e.g. `b7`): an old marker proves a stale cached page. (T4 verification of the relay path is still pending)                  |
| App on cellular shows a READ-ONLY banner                                 | By design: off-LAN the app reads the SmartBuildOS cloud mirror, a read-only channel — settings and simulation need the home network                                                                                        | Nothing to fix. Back on the LAN the app climbs to the relay/JS API on its own (it retries every 5 minutes)                                                                                                                                              |
| `Driver Version` property shows `08302026.x`                             | A hand-stamped bench build is installed, not a store release — releases carry the repo's timestamp version scheme                                                                                                          | Download the current release from the SmartBuildOS driver store and re-add it; never ship bench files to client projects                                                                                                                                |
